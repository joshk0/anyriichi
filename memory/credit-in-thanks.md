Record every preexisting project, site or data source we build on (information, data, ported code, or design inspiration) in the top-level `THANKS.md`: who, what we took, where it lives in the repo.

**Why:** the owner wants the work of others we build on acknowledged explicitly and kept current (asked 2026-11-25).
**How to apply:** when research or code uses an outside source, update THANKS.md in the same commit; note licences for ported code. Also in CLAUDE.md working rules. Related: [[owner-working-style]]
